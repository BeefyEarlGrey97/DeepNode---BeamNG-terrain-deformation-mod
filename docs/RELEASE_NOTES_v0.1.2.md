# DeepNode v0.1.2 — tyre mud, sand and wet looks; ~60 % less memory growth (2026-10-28)

## New looks
- **Mud on tyres:** a smooth clay coat (tread first, then shoulders and sidewalls down to the rim,
  ragged edges, tread relief under the mud) in the colour of the mud you drove through, a little
  lighter as it dries. Replaces the blotchy "camo" look.
- **Sand on tyres:** sand packs into the tread grooves with the lugs showing, light dust down the
  sidewall, in the sand's own colour. Replaces the solid grey "cheesecake" band.
- **Wet tyres:** a muddy-water sheen, streaked where water runs off, instead of a uniform black film.
- Tyre textures are generated by scripts (`art/deepnode/bake_*.py`); no BeamNG texture is copied.

## Fixed
- Tyre coat changed colour and type on hard ground next to the mud (pit edges, start lines): tyre mud
  now only changes on real mud/sand.
- Old `gui.json` files pinned texture paths from before the rename (missing textures): the GUI now
  saves only the kind colours, and older files are cleaned when loaded.

## Faster / less memory
- **Mesh objects reused by size:** engine memory grows whenever an object gets a mesh of another size;
  freed objects now go back out for meshes of the same size (87 % of the time).
- Road-decal overlay meshes padded ~60 % less; rebuilds identical to the shown mesh are not uploaded
  (4.4 %); tyre colour update without per-tick allocations.
- No settings were changed.

## Benchmark (gridmap_v2, 8 Percherons, vanilla physics, orbit camera on truck 1, vsync off)
Same session, v0.1.1 code swapped in and out, 14 runs each:

| | v0.1.1 | v0.1.2 |
|---|---|---|
| fps mean (low 1 %) | 45.9 (24–35) | 45.3 (28–34) — equal within run-to-run noise (±3 fps) |
| memory, 5 fresh runs after start | +244–268 MB | +96–113 MB |
| memory per run once warmed up | +12 to +26 MB | +0.6 to +5 MB |
| repeat runs in existing ruts | 24 MB/min | 19.5 MB/min |
| physics (sim/wall time) | 0.998–1.000 | 0.998–1.000 |

Mod off in the same session: 74.6–79.3 fps.

## Install
Download `DeepNode-v0.1.2.zip` and drop it, unextracted, into
`%LOCALAPPDATA%\BeamNG\BeamNG.drive\current\mods\`. Remove the older DeepNode zip (or an unpacked copy) first.
Settings in `<user folder>/settings/deepnode/gui.json` are kept (only kind colours are read from it now).

## Known issues
- Frame rate: ~45 fps with 8 trucks in vanilla mode (75–79 with the mod off): each mesh upload costs
  engine time (createMesh ~1.2 ms, shadow pass); drawing 64 tyre skins ~0.8 ms.
- Rut deepening behind the front axle can lag seconds when driving in existing ruts.
- Mud colour on tyres tuned on gridmap_v2; johnson_valley not checked yet.
- Sand and vanilla physics mode still use the full mud mesh.
