# DeepNode v0.1.4 — 4.3 MB download (2026-10-29)

Same mod as v0.1.3, smaller and quicker to load:

- Tyre textures are now compressed DDS at half resolution (NVIDIA Texture Tools, BeamNG's own
  formats). The zip went from 18.3 MB to about 4.3 MB.
- Checked in game with wheel close-ups (mud and sand coats, wet film): no visible difference.
- No settings or behaviour changed (tyre mud build-up, colour fade, heavy physics default and the
  "Experimental decal road" switch are as in v0.1.3).

## Install
Download `DeepNode-v0.1.4.zip` and drop it, unextracted, into
`%LOCALAPPDATA%\BeamNG\BeamNG.drive\current\mods\`. Remove the older DeepNode zip first.

## Known issues
See v0.1.3 (frame rate with 8 trucks, vanilla-mode decal overlay look, rut deepening lag, sand mesh).
