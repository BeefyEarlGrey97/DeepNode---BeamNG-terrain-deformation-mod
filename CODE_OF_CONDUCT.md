# Code of Conduct

Be respectful and constructive. Critique code and measurements, not people.

- No harassment, personal attacks, discrimination or unwelcome sexual attention.
- Assume good faith; explain reasoning and show numbers.
- Do not publish other people's private information.

Maintainers may edit or remove comments, close issues and pull requests, and block people who break
these rules. Report problems by opening a private security advisory on the repository or by
contacting the maintainer, @BeefyEarlGrey97, through GitHub.

Adapted from the Contributor Covenant 2.1 (https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
